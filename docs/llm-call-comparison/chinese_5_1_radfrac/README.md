# CHN51 main-control LLM call comparison

These two files repeat the complete model input and output inside every call record so the difference in call count and token usage is directly inspectable.

| Method | Calls | Input tokens | Output tokens | Total tokens | Provider cost |
| --- | ---: | ---: | ---: | ---: | ---: |
| Script Agent | 2 | 269,475 | 26,976 | **296,451** | $1.536879 |
| ReAct | 10 | 1,309,384 | 10,602 | **1,319,986** | $6.864980 |

ReAct used **4.45×** as many main-control tokens. Its full task/context block is repeated inside all ten records, together with the evolving memory and observation context.

## Provenance

Script Agent's initial input and both raw outputs were persisted exactly. The second Script input combines the exact persisted base messages with the deterministic static-contract feedback generated by the recorded harness code.

ReAct persisted exact provider telemetry and raw outputs, but not the literal per-step input message bodies. Its input messages are deterministically reconstructed from the persisted task/context artifacts, memory update rules, prompt reducer, and prior observations. Every ReAct record is marked with this provenance. Local filesystem roots and run/session identifiers are redacted.
